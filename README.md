## 📌 About
The PG Rooms Management System streamlines the process of PG accommodation management.  
- PG owners can **add**, **edit**, and **manage** room details including availability, rental terms, and images.  
- Users can **search** for available PG rooms based on filters, **apply** for rooms, and track their applications.  
- Owners receive user applications and can review or respond accordingly.  
- Built with a focus on security, scalability, and clean user-interface design.

---

## ✅ Features
- Owner registration & login  
- User registration & login  
- Owner dashboard: add new PG rooms, update existing room details, upload images  
- User dashboard: browse listings, filter by location/price/amenities, apply for rooms  
- Application management: owners view and manage applications  
- Responsive UI for both owner and user flows  
- Database connectivity for storing users, rooms, applications  
- Simple and intuitive navigation

## 🧰 Tech Stack
- **Frontend:** HTML, CSS  
- **Backend:** PHP  
- **Database:** MySQL  
- **Server Environment:** WAMP/MAMP/XAMPP  
- **Version Control:** Git & GitHub
